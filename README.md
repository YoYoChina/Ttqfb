# 星湾躲猫猫 APP · v3 前端（传 GitHub 的这一包）

## 这一版修了什么

1. **二维码全部重写**：根因是旧版 segno 对短码自动生成 **Micro QR**（只有左上角 1 个定位标记，
   微信/华为/jsQR 都扫不出来）。现在强制标准 QR（3 个定位标记）+ 4 模块静区 + **PNG 位图**，
   不再用会被 WebView 裁掉的 SVG。11 个码用真实解码器逐个验过，全部能扫出原文。
2. **倒计时**：管理员统一下发段数/时长/全局计时模式；成员端「单独显示 / 三个并排」只是
   **本地视图偏好**，切换不请求服务器、不重置时间（旧版会调管理员接口触发 reset）。
3. **身份由管理员指定**：不用抽签也能逐个设抓捕者/躲藏者，或一键批量；开赛最少人数自定义。
4. **积分管理**：管理员可手动把任意成员设为某个分数，或 ±0.5，自动记入积分流水。
5. **小球管理**：改名、重置已扫、删除、全部重置；二维码可点开放大方便扫。
6. **地图纠偏**：创建比赛可选坐标来源（GPS/WGS-84 或 高德/GCJ-02），后端统一转 WGS-84 入库；
   切换瓦片源时场地圆圈按当前坐标系重画，不再和轨迹错开几百米。雷达保留。
7. **权限**：APK 原生在启动页就一次性申请相机 + 精确定位，并在 WebChromeClient 里
   显式放行 getUserMedia / geolocation；网页版首次进入也有「同意并开启」弹窗。
8. UI 完全沿用上一版 ins 风，没动配色和图标。

## 怎么用

### 已有仓库（你现在的）
1. 把 `星湾APP_前端_v3.zip` 传到仓库根 → 现有解压工作流自动更新 `frontend/` 并重发 Pages。
   （旧版解压工作流里那个 Capacitor 打包任务若报红，忽略即可，已作废。）
2. **手动贴 2 个文件**：`.github/workflows/unzip.yml` 与 `.github/workflows/android.yml`，
   完整内容在 `手动替换工作流_v3.txt`（机器人不能提交 workflows 目录，只能人工贴一次）。
3. Actions → 选「打包 Android APK（权限修复版 v3）」→ Run workflow → Artifacts 下载 APK。
4. 手机里如果装过旧 PWA/APK，**先清一次浏览器缓存 / 卸载旧包**（SW 版本已 bump 到 v3）。

### 后端
**必须同时升级后端**，否则二维码仍是旧的 Micro QR、也没有积分/小球管理接口。
把 `星湾APP_后端升级.sh` 传到服务器 /tmp，`sudo bash /tmp/星湾APP_后端升级.sh`。
升级只替换 `/opt/starven/backend/app/` 的 py 文件，**不动 data/.env/nginx/证书**，重启后
`curl -s 127.0.0.1:8080/api/health` 应返回 `"edition":"v3-qr-fixed"`。
